# Bank Account Program

Program Java sederhana yang mensimulasikan operasional rekening bank (saldo awal, setoran, dan penarikan) dengan integrasi 'ArrayList' untuk mencatat riwayat transaksi.

## Deskripsi Program
Program ini dibuat untuk memenuhi tugas eksplorasi pemrograman berorientasi objek (OOP) di Java yang terdiri dari dua class:
- "BankAccount.java": Berisi logika utama saldo, pembuatan konstruktor saldo awal, method 'deposit()', 'withdraw()', 'getBalance()', serta 'ArrayList' untuk pencatatan riwayat transaksi.
- "BankDemo.java": Class utama untuk menjalankan alur demonstrasi transaksi secara berurutan sesuai kriteria tugas.

## Library / Modul Tambahan
- "java.util.ArrayList": Digunakan untuk menyimpan dan mengelola daftar riwayat transaksi secara dinamis.
